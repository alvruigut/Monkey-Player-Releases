# Monkey Player Releases

Repositorio público de distribución de **Monkey Player**.

Este repositorio **no contiene el código fuente** de la aplicación. Su finalidad es publicar versiones estables para Windows, Android y Fire TV.

## Última versión

**v1.1** (`1.1.0+50`)

Los instaladores se publican en la sección **Releases** de GitHub:

- `Monkey-Player-Windows.exe`
- `Monkey-Player-Android.apk`
- `Monkey-Player-FireTV.apk`

Cada Release incluye también:

- `checksums.txt` — hashes SHA-256 de los binarios.
- `release-manifest.json` — metadatos de versión, plataforma, tamaño y hash.

## Actualizaciones

Monkey Player podrá consultar la última Release pública de este repositorio para detectar nuevas versiones y seleccionar automáticamente el archivo correspondiente a cada plataforma.

## Código fuente

El código fuente y el flujo de desarrollo se mantienen en un repositorio privado separado.
